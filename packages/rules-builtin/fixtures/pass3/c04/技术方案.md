# 采购付款审批流技术方案

## 一、架构
审批流基于现有流程引擎实现，采购系统在提交采购单时创建流程实例，按金额选择审批模板。
付款服务订阅流程引擎的“流程结束”事件，与银企直连接口对接完成付款。

## 二、审批模板
| 模板 | 金额区间 | 审批节点 |
| --- | --- | --- |
| T1 | 金额 < 1 万 | 部门负责人 |
| T2 | 1 万 ≤ 金额 < 5 万 | 部门负责人 → 采购总监 |
| T3 | 金额 ≥ 5 万 | 部门负责人 → 采购总监 → 财务总监 |

## 三、付款
审批通过的采购单不区分金额，付款服务收到流程结束事件后直接调用银企直连接口打款，中间不设人工确认步骤。
付款接口调用失败时重试 3 次，仍失败则发送通知给申请人和财务专员。
所有审批与付款操作写入审计日志，保留 3 年。
