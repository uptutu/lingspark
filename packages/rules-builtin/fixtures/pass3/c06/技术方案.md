# 客服工单系统重构技术方案

## 1. 目标
- 支撑日均 5 万张工单、峰值 200 张/秒的创建请求。
- 工单列表查询 P95 延迟低于 300 毫秒。
- 工单全文检索支持按标题、描述、客户手机号尾号检索。

## 2. 存储选型
- 工单主数据存 MySQL，按租户 ID 分 16 个库。
- 工单全文检索引入 Elasticsearch 集群（3 节点），通过 binlog 订阅将工单数据同步到索引，延迟目标 5 秒内。
- 附件存对象存储，单个附件不超过 20 MB。

## 3. 工单流转
- 状态：待分配、处理中、待客户反馈、已解决、已关闭。
- 客户 72 小时未反馈的工单自动转为已解决。
- 已解决工单 7 天后自动关闭，关闭前客户可重新打开。
