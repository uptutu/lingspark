# 营销消息频控技术方案

## 1. 频控计数
- 以“用户 ID + 自然日”为 key 在 Redis 计数，TTL 48 小时。
- 买家账号的营销类消息计数上限为 3；交易类消息走独立通道，不读取也不累加该计数。
- 商家账号使用独立计数 key，招商通知上限为 5。

## 2. 静默时段
- 静默时段为 [22:00, 08:00)，按用户设置的时区计算，未设置时区的按北京时间。
- 静默时段内产生的营销消息直接丢弃，不做次日补发。

## 3. 渠道
- 本期接入 App 推送、站内信两个渠道的频控。
- 渠道枚举中预留 SMS，下期短信频控上线时启用，本期代码不走该分支。

## 4. 监控
- 每日统计被频控丢弃的消息量，超过当日营销发送量 40% 时告警给运营。
