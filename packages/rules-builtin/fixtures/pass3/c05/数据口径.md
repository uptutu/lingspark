# 搜索核心指标数据口径

## 1. 基础定义
- 一次搜索：用户提交一次查询词并返回结果页，翻页、切换排序不算新的搜索。
- 零结果搜索：返回商品数为 0 的搜索。
- 统计范围：App 与小程序的主搜入口，不含店铺内搜索。

## 2. 指标口径
2.1 搜索点击率 = 至少产生一次商品点击的搜索次数 ÷ 全部搜索次数；分母包含零结果搜索。
2.2 零结果率 = 零结果搜索次数 ÷ 全部搜索次数。
2.3 搜索转化率 = 搜索后 24 小时内下单的搜索次数 ÷ 全部搜索次数，同一次搜索多次下单只计一次。

## 3. 统计规则
- 按自然日统计，以北京时间 0 点切分。
- 剔除爬虫与内部测试账号流量。
- 数据每日 9:00 前产出，存放于搜索日报看板。
