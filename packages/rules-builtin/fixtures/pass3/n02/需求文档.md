# 优惠券后台配置需求文档

## 1. 背景
支撑双十一平台券投放，运营需要自助配置满减档位、领取限制与有效期，不再依赖研发改配置。

## 2. 配置规则
2.1 满减券由运营配置门槛与减免金额，减免金额不得超过门槛的 30%。
2.2 无门槛券面额上限 20 元，可限定“仅首单可用”。
2.3 有效期支持两种方式：固定起止日期，或领取后 N 天有效（N 取 1 至 30）。
2.4 领取限制按实名用户计算，可配置每人限领张数。

## 3. 使用规则
3.1 一笔订单最多使用 1 张平台券，平台券之间不可叠加。
3.2 平台券可与 1 张店铺券同时使用，先扣店铺券再扣平台券。
3.3 订单部分退款时，优惠金额按商品实付比例分摊退回。

## 4. 本期范围
本期做：满减券、无门槛券的配置与使用。
本期不做：折扣券（打 8 折类），下期上线。
